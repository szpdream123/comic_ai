# 示例：区分证据与推断

以下均为虚构示例，仅说明分析方式。

输入：第2场，林遥把唯一的铜钥匙扔进井里。第3场，紧接上一场，林遥掏出那把铜钥匙开门。要求保留扔钥匙和成功开门两个事件。

诊断：高优先级，硬性矛盾。第2场「唯一的铜钥匙扔进井里」与紧接的第3场「掏出那把铜钥匙」缺少取回过程。

局部修改建议：在第3场开头增加「林遥用井旁的吊桶打捞铜钥匙，确认钥匙仍在桶中，随后取出开门」。这是新增过渡情节建议，井深和打捞可行性仍需作者确认；如果不能新增动作，应先调整既有约束，不能直接把“唯一”改成“备用”。

反例：输入只有「林遥突然决定离开」，没有前文。应标注「动机需结合前文核对」，不能断言角色崩坏，也不能自创她收到死亡通知。
