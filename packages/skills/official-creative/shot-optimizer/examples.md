# 示例：固定时长下拆分复杂动作

输入：S03 共8秒，白衣女侠从门外走进来、拔剑、转身与追兵对打，镜头同时快速推近、拉远并环绕。必须保留入门、拔剑与交锋，未指定模型。

诊断：8秒内包含多段空间位移与交锋；同时推近和拉远的指令冲突。建议拆为 S03-A 3秒、S03-B 2秒、S03-C 3秒，合计8秒。时长为创作分配，能否分别生成需依据实际模型限制确认。

S03-A 提示词：白衣女侠从木门外进入室内，右手扶剑柄，步至门内停住；中景，固定机位，门外冷光照亮轮廓，结束时人物面向室内。

S03-B 提示词：同一白衣女侠停在门内，右手拔剑出鞘，持剑转身面向门口；中近景，固定机位，服装与门外冷光延续上一镜。

S03-C 提示词：女侠持剑面向门口，与入门的追兵完成一次明确的挡剑交锋；中景，固定侧机位，结束时双方短暂停住，延续女侠右手持剑状态。

说明：追兵数量、外观和参考素材未提供，不自行创建身份。将笼统「对打」收敛为一次挡剑是建议；如果必须保留连续多回合，应说明8秒节奏风险并提出延长方案，不能宣称约束已全部满足或保证生成成功。
