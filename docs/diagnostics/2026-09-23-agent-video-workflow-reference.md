## 用户表达的体验目标

自由会话应支持持续完成创作：每一步给出清晰产物与真实状态，提供几个具体的后续选项，也允许用户自由输入调整要求。

用户不必重述已经确定的人物、场景、参考素材与参数。例如“给这段书店告白加一点桂花飘进窗的细节”，应定位当前片段、整理调整后的提示词，再展示将生成的内容和预计积分，由用户确认生成新版本。

## 值得采用的交互

| 环节 | 会话中展示 | 展开后或后续操作 |
| --- | --- | --- |
| 剧本与计划 | 简短说明、当前阶段 | 查看阶段进度和待完成工作 |
| 素材清单、故事板、视频提示词 | 紧凑文档卡片、标题、版本等信息 | 宽敞详情视图，完整阅读、复制、编辑、下载 |
| 参考素材 | 集中排列角色与场景缩略图 | 检查素材、明确后续片段所用引用 |
| 故事板 | 按场景组织、清楚区分镜头 | 逐镜查看画面、对白/声音、景别、运镜、时长 |
| 视频片段方案 | 每段的参考图、提示词摘要、模型参数、预计积分 | 展开完整提示词、选择生成片段、查看合计并确认 |
| 生成过程 | 每片段自己的排队、生成、失败或完成状态 | 取消等操作与真实任务状态一致 |
| 成片 | 原任务卡片呈现可播放视频、消耗与操作 | 下载、继续修改、继续下一段 |
| 修改 | 本次调整说明、保留的设定、待生成新版本 | 重新报价和确认；旧结果保留可追溯 |

输入框上方可呈现紧凑阶段状态；执行细节按需展开。后续建议应根据当前产物和任务状态更新，不能在已生成或正在生成时再次建议启动同一个任务。

### 文档与生成规则

| 产物 | 内容与规则来源 | 下一步用途 |
| --- | --- | --- |
| 创作设定与素材清单 | 从用户剧本提取角色、场景、道具、画面比例、风格和已有素材；借鉴参考文档的清晰分组 | 用户补充或确认，复用已有素材，生成缺失参考图 |
| 故事板.md | 借鉴参考中的“场景说明／场面调度＋镜号、景别、画面、声音、运镜、时长”；镜头设计沿用项目分镜 Skill | 让用户检查剧情、镜头顺序、节奏和覆盖情况 |
| 分镜提示词.md | 使用用户选择且有权使用的项目分镜 Skill；结合故事板、参考素材和所选模型能力整理成逐视频片段的生成提示词 | 查看、修改、复制、下载及准备生成方案 |

故事板是创作方案，分镜提示词是按视频片段整理的执行方案。两者通过稳定的镜号和片段编号关联，不重复要求用户填写同一份内容。一个视频片段可以包含多个镜头。若项目 Skill 已直接产出完整执行提示词，适配层只整理格式和补足模型参数，不重复改写创作意图。

已有代码同时存在 Skill 广场工作流阶段 `shot`、提示词模板类别 `shot`，以及用于故事板图片生成的 `storyboard` 类别，接入时需要区分，不能仅凭名称混用。执行器已能加载用户本轮选择的广场 Skill；后续实施需验证连续多轮中的选定 Skill 是否稳定沿用。

优先使用明确选择的 Skill；没有选择时才按现有默认配置解析。使用在线实际配置，不能把仓库种子模板误当成线上当前 Skill。加载失败应明确提示。仓库种子分镜模板包含竖屏、强冲突及 JSON 输出要求，因此需要协调用户的实际题材、比例及 Markdown 展示需求：用户已确认的创作要求优先，允许保留结构化生成再渲染为 Markdown，不修改全局 Skill 原文。

每个片段的文档应包括：片段编号与覆盖镜号、实际时长、参考素材、画面与动作、镜头衔接、对白与声音、风格及必要约束。模型相关约束由真实能力提供；不固定套用参考中的 15 秒、16:9、无音乐或特定模型名称。

### 会话中的完整路径

1. 理解剧本与需求：仅询问会影响结果且上下文无法确定的信息，形成简短计划。
2. 素材整理与参考图：产出素材清单，复用已有授权素材；需要付费生成时沿用现有审批模式。
3. 故事板设计：按场景和镜头组织，支持用户在详情中检查与修改。
4. 分镜提示词：按项目 Skill 和实际模型限制整理片段，生成版本化 Markdown 文档。
5. 生成方案：展示片段、引用素材、提示词摘要、参数、逐项预计积分及合计；允许查看全文和选择片段。
6. 任务与成片：用真实任务状态驱动排队、生成、失败和播放结果；刷新后可恢复，防止重复提交。
7. 继续创作：提供与当前状态匹配的少量建议，支持“生成下一段”或自然语言修改当前片段。

这些阶段是可前进和回退的创作进度，不强迫用户逐页操作。已有剧本或参考素材时可直接复用，用户只要求提示词时停在文档产出，不自动生成媒体。

### 页面组织

- 会话中展示简短说明、紧凑文档卡片和素材／视频卡片，长正文进入宽敞详情视图；文档支持复制、下载和继续编辑。
- 故事板详情按场景分组、逐镜排列；提示词详情按视频片段排列。标题、时长、参考素材和正文层级固定。
- 输入框上方呈现一条紧凑阶段栏，详细执行记录折叠。
- 成片保留下载、再次生成、用作参考和继续调整等真实可用操作；其他视频工具按能力逐项接入。

### 自然语言修改与计费

例如“给这段加桂花飘进窗的细节”：根据当前选中视频及会话上下文定位片段，保留人物、场景和已确定参数，生成新的提示词版本并简述变化。若存在多个同样可能的目标，先让用户选择片段。

修改后重新计算报价，展示这次将生成的片段，再沿用现有生成审批模式提交。旧文档和旧视频保留；只重做受影响片段。修改提示词后重新生成必须准确命名，不能冒充对原视频的局部重拍。

积分展示来自真实计价服务；待确认内容必须对应同一份提示词、素材和参数。修改其中任一影响生成或价格的内容，需要使旧报价失效并重新确认，不能沿用旧授权提交不同任务。重试和重复点击需复用现有幂等机制。

### 实施顺序与验收

第一阶段打通“剧本 → 素材／故事板／提示词文档 → 真实报价及确认 → 成片 → 一轮自然语言修改”的完整路径。复用现有 creative.plan、creative.document、素材授权、审批和生成任务能力，保持现有对外接口、签名及数据结构，逐处小范围补齐；需要改变契约的部分单独列出，不在此方案中假定已获变更授权。

第二阶段依据实际接口和模型能力接入局部重拍、高清、延长、编辑、补帧、音效、对口型、音乐。不能以可点击但无法执行的工具栏作为完成标准。

核心验收：

- 用户选择的分镜 Skill 生效且连续多轮保持一致；生成的 Markdown 可读、可下载、可继续编辑。
- 故事板镜头到视频片段的映射完整，时长符合模型能力；参考样例中的 31 秒不能未经说明变成 27 秒或超过片段上限。
- 确认卡中展示的内容与实际提交一致，积分来自真实报价，重复确认不会产生重复任务。
- 只要求文档不生成媒体；修改一个片段不重做全片；失败可重试且旧结果保留。
- 状态、计费及后续建议与真实任务一致；无法支持的功能不虚假承诺。
- 桌面和窄屏均无横向溢出，长提示词不挤在多重小滚动框中。
