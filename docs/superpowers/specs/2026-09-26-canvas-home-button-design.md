# 画布返回列表按钮

2026-09-26 用户纠正：常驻返回按钮应返回「新画布 → 全部画布」列表，不能返回首页。按钮文案为「返回画布」，以下以此更正为准；原 Logo 菜单的「回到主页」仍保留原目的地。

## 目标与设计

在画布左上角标题栏最前方常驻一个「← 返回画布」按钮，退出当前编辑页面并返回全部画布列表，随后依次保留 Logo、项目名称、项目切换与使用帮助。

布局：`[ ← 返回画布 ]  [ Logo ▾ ]  画布项目 1 ▾  使用帮助`

对比方案：仅增加箭头占用空间少，但目的地不明确；另设悬浮按钮容易与画布工具争夺空间。因此选择标题栏内的箭头加文字按钮。

## 视觉与交互

- 延续现有暗色浮层与圆角；按钮高度 36px，箭头 18px，文字 14px、中等字重；字体沿用产品字体，不新增字体资源。
- 调色参考：标题栏炭黑 #17171F，文字月白 #F5F7FB，次要文字灰 #B7B7C7，描边淡紫 #7770C7，悬停底色 #302C4B；优先使用现有主题变量，兼容浅色主题。
- 常态有轻微描边，悬停背景增强，键盘聚焦具有清晰轮廓；不使用持续动画。
- 窄屏优先压缩项目名称与帮助入口，保留返回按钮文字，不遮挡顶部工具或 AI 面板。
- 使用原生 button，支持鼠标、触屏、Enter 和空格，辅助说明「退出当前画布，返回全部画布」。

## 导航与保存

- 使用已有 onOpenProjects / set-nav-tab(new-canvas) 入口，明确返回全部画布列表，不调用浏览器历史返回。和首页菜单共用退出前保存保护。
- 退出前完成当前画布待保存内容的提交；复用已有保存方法和错误处理，保存失败留在画布并明确提示。
- 处理中禁用重复点击；成功后正常卸载画布。保留原 Logo 菜单入口，不删除或重置画布内容，不主动取消已有生成任务。
- 不改接口、数据库、模型调用或其他页面布局。

## 验证

检查常态、悬停、键盘聚焦、窄屏及浅色主题；验证点击只执行一次导航，保存成功后返回全部画布列表，失败保留画布；完成语法、相关现有测试及生产构建验证。浏览器实际结果与无法验证的部分分别记录。

## 自查

范围限于画布导航入口及必要的退出保存保护。已明确目的地、保存失败行为、重复点击和响应式布局，没有未定项。
