# 新手引导文案后台配置设计

## 目标

在现有管理后台新增独立的“新手引导”页面，让有系统设置权限的管理员可视化编辑首次登录引导文案，并可在核心操作之间新增提示步骤。核心操作的触发条件和状态转换继续由代码固定，提示步骤只通过“下一步”推进。

## 配置范围

- 欢迎卡片：眉题、标题、说明、主按钮、跳过按钮。
- 四个基础步骤：眉题、标题、说明。
- 剧本准备步骤：示例剧本按钮、自己的剧本按钮。
- 生成处理中与确认预览阶段：眉题、标题、说明。
- 完成卡片：眉题、标题、说明、完成按钮。
- 提示步骤：插入位置、安全目标、眉题、标题、说明和“下一步”按钮。最多 12 个，按后台列表顺序展示。

所有字段为纯文本，保存前去除首尾空白并限制长度。按钮和眉题不超过 30 个字符，标题不超过 60 个字符，说明不超过 160 个字符。核心字段空值或非法值回退到代码内默认文案；非法提示步骤会被拒绝或过滤。

## 架构

配置使用现有 `runtime_config_entries`，配置键为 `creator.first_login_onboarding`。配置保留固定的核心步骤对象，并增加有序 `tips` 数组。每个提示步骤只能从代码登记的插入位置和目标键中选择；新增页面目标时由开发者登记一次，之后运营可直接配置。后端提供专用规范化函数、管理员读取/保存接口和前台只读接口；保存复用现有配置修订与审计机制。

管理后台新增独立导航页，不让管理员直接编辑 JSON。页面左侧按欢迎、核心步骤、提示步骤和完成阶段分组编辑，提示步骤支持新增、删除和同一插入位置内排序；右侧实时渲染与前台相近的卡片预览。视觉延续现有后台的浅色、紧凑、工具型风格，不引入新的设计体系。

前台在生产工作台初始化时异步读取公开配置，并与内置默认文案合并。配置接口失败、超时或返回非法数据时静默使用内置默认文案；新手引导本身仍可正常开始和完成。

## 数据流

1. 管理员打开“新手引导”，后台读取当前规范化配置。
2. 管理员编辑字段，右侧预览即时更新，不写入服务器。
3. 管理员可新增提示步骤，从插入位置和安全目标下拉框中选择，不接触选择器或动作名。
4. 管理员点击保存，客户端提交完整配置和修改原因。
5. 服务端校验权限、幂等键、步骤数量、目标键及字段长度，规范化后写入运行配置并记录审计修订。
6. 后续新注册用户首次进入工作台时读取最新配置并显示；已经打开的引导不在中途热切换。

## 权限与安全

- 读取需要 `settings.read`，保存需要 `settings.write`。
- 前后台渲染所有配置文字前必须 HTML 转义，禁止配置 HTML。
- 接口只接受固定字段，未知字段不会进入前台配置。
- 不开放 CSS 选择器、任意动作名或首次登录判断配置；提示步骤只能使用服务端返回的目标目录。
- 核心步骤不可删除，提示步骤不能执行创建、提交、跳转等业务动作。

## 异常处理

- 数据库无配置：返回内置默认文案。
- 单字段为空、超长或类型错误：该字段回退默认值。
- 前台请求失败：继续显示内置文案，不阻塞页面。
- 保存失败：保留表单输入并显示错误，不伪装成功。
- 并发更新：沿用运行配置的最后写入和修订记录能力，管理员可从系统设置历史回滚。

## 测试

- 后端单元测试覆盖默认值、合法覆盖、空值/超长/未知字段回退。
- HTTP 测试覆盖公开读取、管理员权限和保存后的读取结果。
- 前端测试覆盖配置合并、HTML 转义、默认回退和卡片渲染。
- 管理后台静态契约测试覆盖导航、表单字段、预览和保存接口。
- 浏览器验收覆盖管理员修改文案后，新注册用户首次登录看到新文案，老用户仍不触发。

## 非目标

- 不支持增删核心步骤；只支持增删提示步骤。
- 不支持任意 CSS 目标、任意跳转、示例剧本内容或触发事件。
- 不支持灰度、定时发布、多语言或按用户分群。
- 验收通过前不提交、不推送。
