# 会员基础版显示与套餐说明配置设计

## 目标

- 后台会员套餐档位把 `experience` 显示为“基础版”。
- 前台会员套餐卡片的说明文字由后台逐套餐配置，不再使用会员档位写死文案。

## 兼容策略

- 保留数据库、接口和业务逻辑中的稳定值 `experience`，不新增 `basic` 枚举，不做数据迁移。
- 只调整后台管理界面的中文标签，因此历史套餐、会员状态和支付逻辑保持不变。

## 数据流

- 后台套餐编辑抽屉新增“前端展示说明”字段。
- 字段读取并写回现有 `displayMetadata.note`，不新增接口字段或数据库列。
- 保存时以专用字段为准；清空字段时删除已有 `note`，同时保留 `displayMetadata` 中其他高级配置。
- 前台后台会员套餐仅展示 `displayMetadata.note`；未配置时不显示说明文字。
- 企业版等非后台会员套餐继续使用现有静态说明。

## 界面与验证

- 后台套餐列表、已配置套餐提示和档位下拉统一显示“基础版”。
- 为后台表单预填、保存和前台无硬编码兜底增加回归测试。
- 运行后台 UI 测试、会员定价弹窗测试和 diff 空白检查。
