# 会员套餐显示、说明与拖拽排序设计

## 目标

- 后台会员套餐档位把 `experience` 显示为“基础版”。
- 前台会员套餐卡片的说明文字由后台逐套餐配置，不再使用会员档位写死文案。
- 后台会员权益套餐和积分套餐通过鼠标拖动调整展示顺序，前台按该顺序展示。

## 兼容策略

- 保留数据库、接口和业务逻辑中的稳定值 `experience`，不新增 `basic` 枚举，不做数据迁移。
- 只调整后台管理界面的中文标签，因此历史套餐、会员状态和支付逻辑保持不变。

## 数据流

- 后台套餐编辑抽屉新增“前端展示说明”字段。
- 字段读取并写回现有 `displayMetadata.note`，不新增接口字段或数据库列。
- 保存时以专用字段为准；清空字段时删除已有 `note`，同时保留 `displayMetadata` 中其他高级配置。
- 前台会员套餐卡片仅展示 `displayMetadata.note`；未配置时不显示说明文字。
- 企业版等非后台会员套餐继续使用现有静态说明。

## 拖拽排序

- 会员权益套餐复用 `displayMetadata.sortOrder`，积分套餐复用现有 `sortOrder`，不新增数据库字段。
- 两个后台列表在每行增加明确的拖动手柄；只有从手柄开始拖动才调整顺序。
- 松开鼠标后立即保存，按当前列表顺序重写为 `10、20、30...`。
- 复用现有套餐保存接口，不新增批量排序接口；保存会员套餐时保留其他 `displayMetadata`、权益和业务字段。
- 保存期间锁定重复拖动并显示保存状态；任一请求失败时重新加载服务端顺序并提示失败，不保留仅存在于页面内的顺序。
- 会员权益后台列表改为优先按 `displayMetadata.sortOrder` 排序；积分套餐继续按 `sortOrder` 排序。
- 前台会员套餐和积分套餐继续按后端接口返回顺序渲染，不再自行按价格或档位重排。
- “新用户权益”属于内部模板，不参与前台套餐排序，本次不增加拖动。

## 界面与验证

- 后台套餐列表、已配置套餐提示和档位下拉统一显示“基础版”。
- 为后台表单预填、保存和前台无硬编码兜底增加回归测试。
- 为拖动手柄、顺序计算、保存失败恢复，以及前台会员与积分套餐顺序增加回归测试。
- 运行后台 UI 测试、会员定价弹窗测试和 diff 空白检查。
