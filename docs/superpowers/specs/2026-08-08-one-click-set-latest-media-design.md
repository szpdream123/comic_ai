# 双模块“一键设置”设计

## 目标

在剧集工作台的“分镜生图”和“分镜生视频”模块中增加同名的“一键设置”按钮。按钮只处理当前已勾选项目，为每项绑定其最近一次生成成功且存在可用媒体的结果；没有成功结果的项目清空当前绑定。

## 交互

- 按钮文案固定为“一键设置”，位于“全选”之前，复用现有 `episode-replica-stage-tab` 视觉样式。
- 没有勾选项时按钮禁用；勾选状态改变时同步更新可用状态。
- 生图模块处理当前勾选的角色、场景和道具素材。
- 生视频模块处理当前勾选的分镜。
- 操作期间沿用工作台忙碌状态，不弹确认框，完成后保留勾选状态。
- 完成提示汇总设置、清空和失败数量。

## 结果选择规则

1. 强制读取每个勾选项的持久化对话历史，不能只依赖当前页面缓存。
2. 从最新记录向旧记录查找。
3. 明确失败、取消或人工审核状态的记录不可用。
4. 第一条包含可用图片或视频地址的非失败记录即为“最新成功结果”。
5. 较新的失败记录不会遮蔽更早的成功记录。
6. 找不到成功结果时清空该项当前绑定，即使它此前绑定过旧媒体。

## 数据流

生图模块复用资产对话历史接口、`setFixedImage` 和 `clearFixedImage`。成功设置后通过现有资产状态同步函数更新角色图、场景图或道具图预览。

生视频模块复用分镜对话历史接口、`setStoryboardVideo`/`updateShot`。成功设置后更新当前视频、缩略图和分镜卡片；无成功结果时将 `currentVideoAssetVersionId` 设为 `null` 并清空视频预览。

批处理逐项独立执行。单项失败会记录并继续处理其余项目，避免一个异常中断整批；最终统一刷新工作台并显示汇总结果。

## 错误处理

- 无选择：不发请求，提示先选择项目。
- 历史请求失败：该项目计入失败，不把网络错误误判为“没有成功结果”。
- 设置或清空失败：该项目计入失败并继续其他项目。
- 本地演示数据沿用相同选择规则和状态更新，但不调用远程接口。

## 测试

- 工具栏在两个模块均渲染“一键设置”，位置在“全选”之前，且无选择时禁用。
- 生图选择最新成功图片，跳过更新的失败记录。
- 生图没有成功结果时清空固定图。
- 生视频选择最新成功视频，跳过更新的失败记录。
- 生视频没有成功结果时清空当前视频。
- 混合成功、清空和异常时继续执行并输出正确汇总。
- 运行相关前端测试、完整项目测试和 gstack 浏览器交互验收。

## 非目标

- 不改变生成流程、批量生成上限、单条“设为…”操作或数据结构。
- 不新增弹窗、动效、图标、配色和独立批量设置页面。
- 不自动选择项目，也不在操作完成后取消选择。
