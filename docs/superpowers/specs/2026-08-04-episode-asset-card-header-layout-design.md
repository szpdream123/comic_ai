# 生图素材卡片头部布局设计

## 目标

解决素材卡片主标题、“引入到对话框”按钮以及保存/删除按钮挤在同一行的问题。调整后应优先保证标题可读、按钮文字完整，并保持标题可编辑和现有业务动作不变。

## 选定方案

采用两层头部：

1. 第一层为选择圆点和可编辑标题。标题独占除选择圆点外的整行宽度；聚焦编辑时仍使用现有输入框与失焦保存逻辑。
2. 第二层为操作区。“引入到对话框”固定在左侧，保存和删除按钮固定在右侧。
3. 操作区使用正常文档流，不再依赖居中绝对定位或悬浮覆盖，因此窄卡片与不同标题长度下都不会互相遮挡。

## 视觉与交互约束

- 保留现有深色、主题变量、圆角和按钮风格，不引入新的视觉语言。
- 标题不再为同排按钮预留大块空间，短标题完整显示；达到 20 字上限的超长标题仅在真实超出卡片宽度时省略，聚焦后可横向查看和编辑完整文本。
- “引入到对话框”始终完整显示，不缩写文字。
- 保存、删除按钮保持完整点击区域和现有 hover/focus 状态。
- 桌面三列卡片允许头部小幅增高；卡片主体内容不缩小。
- 小屏布局继续单列展示，操作区允许自然换行但不重叠。

## 实现范围

- 调整 `renderAssetCard` 的头部结构，增加明确的标题行和操作行容器。
- 调整 `production-workbench.css` 中标题、导入按钮和工具按钮的定位规则。
- 保持事件 action、数据属性、保存接口和状态同步逻辑不变。

## 验证

- 渲染测试确认标题行与操作行结构存在。
- CSS 回归测试确认导入按钮不再绝对居中，标题获得完整首行宽度，操作按钮不会压缩。
- 复跑现有素材卡片和生图工作台相关测试。
- 在桌面三列布局下检查长标题、短标题、角色/场景/道具三类卡片。
