# 故事板图片双击放大设计

## 目标

在剧集故事板工作台中，为以下两类已加载图片增加详情查看能力：

1. 左侧分镜卡片“故事板”列中的定稿故事板图片。
2. 右侧生成输入区中的图片参考缩略图，包括普通附件和快捷参考图。

用户双击图片区域后打开大图预览。图片保持原始宽高比并完整适配当前视口，不改变现有单击选择、上传、生成、移除或拖放行为。

## 方案选择

### 方案 A：复用现有图片查看器（采用）

给可预览的图片区域附加统一的预览 URL 和名称数据，根节点通过事件委托处理双击，再复用现有 `assetInspector` 与 `asset-image-lightbox`。

优点是改动小、视觉一致、已有遮罩关闭能力可直接复用；两处入口使用同一条逻辑，后续也容易扩展。

### 方案 B：为两处入口分别增加弹窗状态

每处图片维护独立弹窗和事件处理。实现直观，但会重复状态、模板与样式，容易产生行为漂移。

### 方案 C：引入支持滚轮缩放和拖拽的图片查看库

适合像素级检查，但会增加依赖、交互复杂度和回归面，超出本次“查看故事板详情图”的需求。

## 交互设计

- 仅当图片 URL 有效时，图片区域才具备双击预览能力。
- 双击故事板图片或右侧图片参考缩略图后，打开现有全屏遮罩查看器。
- 图片使用 `object-fit: contain`，最大宽高受视口约束，始终等比完整显示。
- 点击图片外遮罩或按 `Escape` 关闭预览。
- 双击移除按钮、上传按钮等控制项不触发预览。
- 单击行为保持原样，右侧参考图仍可正常选择或取消选择。
- 视频、音频、空占位图不进入本次图片预览逻辑。

## 实现边界

- 复用 `episode-workbench-rebuilt.js` 中现有的 `renderAssetInspectorModal` 图片查看分支。
- 在故事板缩略图和生成输入区图片卡片的实际图片区域上输出统一的预览数据属性。
- 在 `index.js` 现有根节点 `dblclick` 事件中优先识别图片预览目标；命中后打开查看器并终止该次双击的其他处理。
- 在现有键盘处理逻辑中支持 `Escape` 关闭图片查看器，不修改其他快捷键。
- 不修改 API、供应商调用、模型配置、数据库或生成任务状态。

## 错误与边界处理

- URL 为空时不输出可预览标记，也不打开空弹窗。
- 图片加载失败时保留浏览器原生失败状态，关闭路径仍然可用。
- 事件目标来自嵌套 `img` 时通过 `closest` 找到预览区域。
- 查看器打开后重复按 `Escape` 不产生副作用。

## 测试与验收

自动化测试先覆盖以下行为并确认在实现前失败：

1. 故事板图片缩略图输出统一的双击预览数据。
2. 普通图片附件和快捷参考图输出相同预览数据，视频与音频不输出。
3. 双击预览目标后写入 `viewerOnly` 图片查看状态并渲染大图遮罩。
4. `Escape` 关闭已打开的图片查看器。
5. 原有生成结果图片查看器测试继续通过。

浏览器验收检查两处入口、视口适配、遮罩关闭、`Escape` 关闭、单击选择和移除按钮不回归，并检查控制台无新增错误。
