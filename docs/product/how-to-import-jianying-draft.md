# 剪映草稿包导入操作指南

本文说明如何把灵曦AI导出的剪映草稿 ZIP 解压并放入剪映专业版。完成后，每个分镜视频会作为独立片段出现在剪映时间线上，可以继续裁剪和调整。

## 准备工作

- 使用 Windows 桌面版剪映专业版。
- 确认准备导出的分镜都已经“设为分镜视频”。未勾选的分镜不会进入草稿包，也不会影响本次导出。
- 确保磁盘剩余空间大于草稿 ZIP 的两倍。
- 导入前关闭正在编辑的剪映草稿。

## 操作步骤

1. 在剪映首页打开“全局设置”，找到并记下“草稿位置”。

   草稿位置可以由用户修改，因此不要直接使用网上提供的固定路径。

2. 回到灵曦AI的剧集工作台，在分镜卡片左上角勾选需要导出的分镜。可以点击列表上方“全选”快速选择当前剧集分镜。

3. 点击右上角“导出”。如果没有勾选分镜，系统会提示“请先选择分镜”，且不会开始打包。

4. 选择“剪映工程文件”，等待浏览器下载 `.zip` 草稿包。剪映与 MP4 导出使用同一组已勾选分镜。

5. 打开下载目录，右键 ZIP 文件并选择“全部解压”。

6. 检查解压后的顶层文件夹。正确结构如下：

   ```text
   项目名-剧集名/
   ├─ draft_content.json
   ├─ draft_meta_info.json
   └─ assets/
      └─ video/
         ├─ 001-剧集名-分镜名.mp4
         ├─ 002-剧集名-分镜名.mp4
         └─ ...
   ```

   打开顶层文件夹后应当直接看到 `draft_content.json`。如果里面还有一层同名文件夹，请使用内层包含 JSON 文件的文件夹。

7. 把整个顶层草稿文件夹复制到第 1 步确认的剪映草稿位置中。

   不要只复制两个 JSON 文件，也不要把 `assets` 里的视频单独移动到其他位置。

8. 完全退出剪映专业版，然后重新打开。

9. 在剪映首页找到与“项目名-剧集名”同名的草稿并打开。

## 验证结果

导入成功后应满足以下条件：

- 剪映首页能看到新草稿。
- 时间线上的视频片段数量与已导出的分镜数量一致。
- 片段按照灵曦AI中的分镜顺序排列。
- 每个片段都可以单独选中、裁剪和移动。
- 播放时间线时画面和原视频声音正常。

## 常见问题

### 剪映首页没有出现草稿

1. 确认已经完全退出并重新打开剪映，而不是只关闭编辑窗口。
2. 再次打开剪映“全局设置”，确认复制目标与当前“草稿位置”完全一致。
3. 检查是否多套了一层目录。剪映扫描到的草稿文件夹内应直接包含 `draft_content.json`。
4. 如果仍未刷新，先打开任意已有草稿再返回首页，或再次重启剪映。

### 草稿可以打开，但提示素材丢失

1. 检查草稿文件夹内是否仍有 `assets/video` 目录。
2. 不要重命名或移动 `001-剧集名-分镜名.mp4`、`002-剧集名-分镜名.mp4` 等素材文件。
3. 删除这份导入失败的草稿文件夹，重新完整解压 ZIP 后再复制。

### 时间线片段数量不对

返回灵曦AI核对勾选状态，并检查每个已勾选分镜是否已经“设为分镜视频”。只有已勾选分镜的当前视频会进入草稿包。调整选择或补齐视频后重新导出，不要把新 ZIP 覆盖解压到旧草稿文件夹中。

### 导出时提示视频信息不完整

部分旧视频可能没有保存时长信息。重新上传该视频，或重新生成并设为分镜视频，然后再次导出。

## 使用限制

- 当前草稿包包含分镜视频主轨道及视频自带声音。
- 当前不自动添加字幕、独立配音、背景音乐、转场和滤镜。
- 剪映草稿格式不是公开标准。剪映升级后如出现兼容问题，请保留下载的 ZIP，并记录剪映版本号。
