# 扩图任务已完成，新画布仍在生成中

- 症状：画布项目 47 的「生成图像 扩图」节点一直转圈；任务中心没有进行中任务。用户确认任务已完成。
- 根因：
  1. 扩图会新建 `status=loading` 且无 `taskId` 的节点。任务中心 `targetType=canvas` 时回写绑到第一个 loading 节点，不是最新扩图节点。
  2. 任务刚变成 `succeeded` 时如果还没有媒体 URL，任务中心桥会立刻结束等待。运行时抛「完成但未返回结果 URL」，catch 只 toast，不清 loading。任务随后从进行中列表消失。
- 修复：
  - 完成回写绑到最新未绑定 loading 节点。
  - 成功但没有 URL 时继续轮询，任务中心仍显示进行中，不提前结束运行时等待。
- 验证：`task-center.spec.mjs` 扩图回写与继续轮询用例通过。
- 状态：DONE_WITH_CONCERNS（需刷新画布后确认卡住扩图节点恢复）
